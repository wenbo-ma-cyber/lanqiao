## W02-01 读数摘要

给出 n 个整数，输出其中的最小值、最大值和所有数之和。

**输入格式**

第一行一个整数 n；第二行 n 个整数。

**输出格式**

输出三个整数：最小值、最大值、总和。

**数据范围**

1 ≤ n ≤ 1,000；每个整数的绝对值不超过 10^6。

**样例输入**

```text
5
3 -2 9 3 0
```

**样例输出**

```text
-2 9 13
```

## W02-02 镜面单词

判断一个只含小写英文字母的字符串，正着读与倒着读是否相同。

**输入格式**

一行，一个字符串 s。

**输出格式**

若相同输出 YES，否则输出 NO。

**数据范围**

1 ≤ |s| ≤ 1,000。

**样例输入**

```text
level
```

**样例输出**

```text
YES
```

## W02-03 元音数量

统计字符串中 a、e、i、o、u 这五种字母出现的总次数，每次出现都计数。

**输入格式**

一行，一个仅含小写英文字母的字符串 s。

**输出格式**

输出一个整数。

**数据范围**

1 ≤ |s| ≤ 1,000。

**样例输入**

```text
algorithm
```

**样例输出**

```text
3
```

## W02-04 第 k 张卡片

将 n 张整数卡片按数值从小到大排列，输出排列后第 k 张的值。相同数字的卡片分别占一个位置。

**输入格式**

第一行两个整数 n、k；第二行 n 个整数。

**输出格式**

输出第 k 小的数值。

**数据范围**

1 ≤ k ≤ n ≤ 1,000；卡片数值绝对值不超过 10^6。

**样例输入**

```text
5 3
8 2 2 9 3
```

**样例输出**

```text
3
```

## W02-05 高于平均值

统计 n 个整数中严格大于这 n 个数算术平均值的个数。

**输入格式**

第一行一个整数 n；第二行 n 个整数。

**输出格式**

输出严格高于平均值的个数。

**数据范围**

1 ≤ n ≤ 1,000；每个整数的绝对值不超过 10^6。

**样例输入**

```text
4
1 2 3 10
```

**样例输出**

```text

```

## W02-06 队伍左移

将长度为 n 的队伍循环向左移动 k 个位置。每次左移把第一项移到末尾。

**输入格式**

第一行两个整数 n、k；第二行 n 个整数。

**输出格式**

输出移动后的 n 个整数，用空格分隔。

**数据范围**

1 ≤ n ≤ 1,000；0 ≤ k ≤ 10^9；每个整数绝对值不超过 10^6。

**样例输入**

```text
5 2
1 2 3 4 5
```

**样例输出**

```text
3 4 5 1 2
```

## W02-07 删除指定读数

从 n 个整数中删除所有等于 x 的数，其余数保持原来的相对顺序。

**输入格式**

第一行两个整数 n、x；第二行 n 个整数。

**输出格式**

第一行输出剩余个数；第二行输出剩余整数。若全部删除，第二行输出 EMPTY。

**数据范围**

1 ≤ n ≤ 1,000；所有整数绝对值不超过 10^6。

**样例输入**

```text
5 2
2 7 2 9 2
```

**样例输出**

```text
2
7 9
```

## W02-08 连续差值

给出按时间顺序记录的 n 个整数，输出每个值减去它前一个值的差。

**输入格式**

第一行一个整数 n；第二行 n 个整数。

**输出格式**

若 n≥2，输出 n-1 个差值；若 n=1，输出 EMPTY。

**数据范围**

1 ≤ n ≤ 1,000；每个整数绝对值不超过 10^6。

**样例输入**

```text
4
3 8 6 6
```

**样例输出**

```text
5 -2 0
```
