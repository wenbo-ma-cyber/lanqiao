## 今天开始

1. 打开第 1 周题目，先独立完成 W01-01、W01-02。
2. 每道题各保存为一个 `.py` 文件，例如 `w01_01.py`。
3. 先运行题面样例，再用本地工具做有限自测。
4. 记录独立／提示／题解后完成、耗时、错误原因；安排隔天与一周后的重做。

## 使用自测工具

需要本机已有 Python 3，无第三方依赖。在本目录打开终端：

```bash
python3 check.py W01-01 /你的路径/w01_01.py
```

也可以从任意目录使用自测工具的绝对路径；路径含空格时加引号。在 Windows 中，按本机环境使用 `python` 或 `py` 替代 `python3`。

- 每个用例启动一个新的 Python 进程，限时 **2 秒**；使用与运行 `check.py` 相同的解释器。
- 通过标准输入传入数据。输出按空白分隔后的 **token** 比较，忽略多余空格和换行，但不忽略数字、文字或额外提示语。
- 超时、运行错误、输出不匹配分别报告。全部通过退出码为 `0`，用例失败为 `1`，参数错误为 `2`。
- 124 组固定用例，每题至少 3 组，包含样例与部分边界。**只是有限自测，不是官方判题，也不测完整比赛环境或内存上限。**
- 第 4 周测评在 90 分钟计时结束后再使用自测工具；计时期间只使用自己的程序和题面样例。

维护资料时，可核验全部参考实现：

```bash
python3 check.py --self-test
```

自测参考实现时会在本目录短暂创建临时文件，运行后自动清理。

## 答案与保留测评

[answers.md](answers.md) 包含分题折叠的思路与参考 Python 代码；`answers.json` 保存相同参考代码，供工具核验使用；`cases.json` 是自测数据。不要在独立练习前阅读答案或测试数据。

**W04-04～W04-08 共 5 题为保留测评。** 题目位于第 4 周文档的折叠区域。折叠只是阅读提醒，某些纯文本编辑器会直接显示内容，并不构成访问限制。请在测评当天才打开该区域。提前看过题目或解法时，不能再把它当作陌生测评，应换 5 道未见题。

90 分钟完成后，至少 4 题独立做出并通过有限自测，作为本套阶段目标。随后补充边界验证和思路说明；此结果不能换算为蓝桥杯分数或获奖概率。
