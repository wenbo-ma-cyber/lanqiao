# 蓝桥算法星图

面向 Python 大学 B 组的36周学习与训练网站。新版将知识学习、陌生题验证、复习修复与模拟复盘分开。学习进度不是获奖概率；日期和每周10小时是参考预算。

## 本地使用

从工作区根目录执行：

```bash
python3 -m http.server 8768 --bind 127.0.0.1 --directory output
```

打开 <http://127.0.0.1:8768/lanqiao-learning/>。如果已有同目录服务，直接使用。发布包解压后可在含 `index.html` 的目录启动同样的静态服务。没有 npm 安装或构建依赖；不要直接用 `file://` 打开。

## 学习与验收

- 42个知识主题、11个训练复盘条目，稳定保留旧 `k01`—`k47` 的学习关联，新增 `k48`—`k53`。
- 每个知识主题包括问题直觉、推导、不变量或正确性理由、完整Python例程、复杂度、Python成本、边界案例、理解问答与四层练习。
- 42个主题对应49条章节阅读任务，全站61道不同外部题。22个主题仍不足两道外部题；站内四层任务已覆盖，但外部练习梯度尚未全部补齐。
- 8道原创混合题默认隐藏方法类别、提示和参考解答。自编题没有在线判题；样例/自测不能标成完整平台评测。
- 第8、12、16、20、24周有混合诊断；第20周提前接触国赛题组，抽题后的试卷不能再作为陌生卷。
- 第29、30周为诊断选修；可以选择“暂缓选修”，系统继续推荐其他任务，不把暂缓算成掌握。
- 8套推荐原卷来自官方2022—2025 Python大学B组目录。页面列出具体卷名、链接、登录要求与核验边界。第28、33、36周安排已见卷复测和专项修复，不冒充新增陌生卷。
- 模拟计时不提供实时判题，也不自动保存成绩。计时在本页会话内跨路由继续，刷新后重置；结束时手动记录实际耗时。
- 模拟档案包括实际原卷来源、是否未见/盲测、逐题结果、耗时、卡点及修复任务。平台费用和登录后题面需开始前核对。

## 掌握与复习规则

“已掌握”由本人核对验收后自评。证据单独统计：同主题至少两个不同可识别题号，均声明陌生、独立完成且完整评测通过，其中至少一道有跨日完整评测复测。没有证据不等于没有能力，旧记录也不会自动补造证据。

下一步优先级为未解决的失败 → 到期复习 → 显式薄弱点 → 学习中/待验证 → 满足先修的新主题。失败后用户原掌握自评保留。

- 一般练习安排隔天和一周复习，失败的次日任务称为“补测”。
- 到期复习仍未完成或依赖帮助：完成本次记录，同时安排次日补测。
- 独立复测通过：按一周、三周延长；三周通过后停止自动延长。
- 同主题同到期日仅合并尚未完成的事项；已完成事项不能吞掉新补测。
- 编辑历史日志会更新证据判断，但不会回写原复习日期；需要新的补测时追加记录。
- 题号累计按人工日志去重，不连接洛谷账号。复习与题数都不是官方成绩。

## 数据与兼容

仍使用 `localStorage` 键 `lanqiao-learning-state-v1`，兼容原v1备份。新增练习证据与模拟档案为可选字段。旧知识主题ID不重新编号；3个原整卷复盘条目调整为同阶段复测窗口，原记录仍保留关联。

记录仅属于当前协议、主机、端口和浏览器；换设备、换网址或清理数据前先导出。导入会校验并要求确认后完整替换，不合并。不要把私人备份加入公开仓库。多标签冲突、存储损坏与保存失败会提示保留和导出，不静默覆盖。

## 验证与打包

```bash
timeout 60 node --test output/lanqiao-learning/tests/*.test.cjs
python3 output/lanqiao-learning/tools/package.py
```

每个Python示例子进程有明确超时。Python3.8语法检查不等于在官方Python3.8.6环境做过全数据性能评测；详见 `验收记录.md`。更新内容后执行打包，避免把旧发布目录上传。
