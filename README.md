# 从这里开始

这是一套可以立即开始使用的 2027 年蓝桥杯 Python 大学 B 组备赛资料。按零基础、每周 10 小时设计，36 周共 360 小时。目标是争取省一晋级并冲击国一；完成任务表不等于达到获奖水平，需要持续用陌生题测评。

## 今天先做三件事

1. 阅读 [第一课](第一课.md)，运行自己的第一个 Python 程序。
2. 打开 [第一周练习](practice/week01.md)，独立完成前两题。不要先打开答案。
3. 在 [备赛记录.xlsx](备赛记录.xlsx) 的“学习日志”中填入日期、活动、题号和耗时。当天只完成这一步也可以，正式第 1 周从 2026-09-28 开始。

## 使用学习记录表

“周计划”列出36周日期、主题、预算和验收事项；实际小时自动按日志日期汇总。“学习日志”预留600条记录，黄色单元格是输入区。

- 日期填真实日期，例如 `2026-09-28`；耗时填分钟，例如 `45`。不要填 `45分钟`。
- 已填日期但漏填耗时会显示“待补时长”；明确填写 `0` 则视为实际零分钟。
- 每次学习记一行。第一次做题选择“首次做题”，重做沿用同一题号并选择“重做”。
- 首次做题且已填日期、题号时，自动生成隔天、一周后的建议复习日期；完成情况填在“复习完成记录”。这是日期安排，不会发送提醒。
- 模拟卷用一条记录填写总时长；如果改为逐题计时，就不要再把整卷总时长重复录入。赛后补题单独记录新增耗时。
- “达标”需要自己根据测评证据选择，表格不会因为累计时间足够就自动认定学会。
- 表中的已记录总时长只包含周计划覆盖的日期；正式开始前的热身可以记录，但不会算入第1周。
- 赛期或个人进度变化时，可以修改日期、主题、预算。各周日期保持连续、不重叠，否则同一条日志可能重复汇总或漏计。
- 不覆盖公式列：“周计划”F列、“学习日志”H/I列。超过600条时，需复制复习公式、验证规则，并扩展周计划中引用到第606行的汇总范围。

## 运行本地自测

需要电脑上已有 Python 3。先把自己的代码保存为 `my_solution.py`。在资料包目录打开终端，运行：

```bash
python3 practice/check.py W01-01 my_solution.py
```

Windows 如果使用 `py` 启动器，可改成：

```powershell
py -3 practice/check.py W01-01 my_solution.py
```

题号以题面为准。自测工具会运行你提供的代码，每个用例有超时限制；仅用于自己编写的练习文件。有限用例通过不代表官方评测满分。没有 Python 时，先按 [Python 官方下载页面](https://www.python.org/downloads/) 安装适合自己系统的 Python 3，或暂用已有在线 Python 环境运行样例。本包不修改系统环境。

## 日程与测评约定

训练日期按 2026-09-28 至 2027-06-06 暂排，省赛4月、国赛6月只是规划假设，正式日期、资格与运行环境以2027年官方通知为准。资料来源见学习指南；这里沿用前一轮已核对的来源，不把旧规则当作2027年定案。

练习时允许逐级请求提示；阶段测评和保留卷独立完成，不看答案或用 AI。第4周只在开始测评时打开后5题。参考代码、测试数据也会透露解法或测试点，请在测评提交后再查看。

第一周另需向学校确认报名负责老师、校内选拔和截止日期。资料包不会自动报名、缴费、联系老师或创建提醒。
