## W03-01 最常见编号

找出出现次数最多的编号。如果多个编号次数相同，输出数值最小的编号。

**输入格式**

第一行一个整数 n；第二行 n 个整数编号。

**输出格式**

输出两个整数：选中的编号和它出现的次数。

**数据范围**

1 ≤ n ≤ 1,000；编号绝对值不超过 10^6。

**样例输入**

```text
6
4 2 4 2 9 4
```

**样例输出**

```text
4 3
```

## W03-02 首次出现顺序

按首次出现的顺序输出各个不同编号。

**输入格式**

第一行一个整数 n；第二行 n 个整数编号。

**输出格式**

第一行输出不同编号数；第二行按首次出现顺序输出这些编号。

**数据范围**

1 ≤ n ≤ 1,000；编号绝对值不超过 10^6。

**样例输入**

```text
6
3 1 3 2 1 5
```

**样例输出**

```text
4
3 1 2 5
```

## W03-03 共同收录

两个清单分别记录一组整数编号。求两份清单都收录的不同编号数。同一清单内重复出现只算一个编号。

**输入格式**

第一行两个整数 n、m；第二行 n 个整数；第三行 m 个整数。

**输出格式**

输出共同收录的不同编号数。

**数据范围**

1 ≤ n,m ≤ 1,000；编号绝对值不超过 10^6。

**样例输入**

```text
4 4
1 2 2 3
2 2 4 3
```

**样例输出**

```text
2
```

## W03-04 库存查询

库存清单中，每出现一次编号代表库存中有一件该编号的物品。回答 q 次查询：每次给出编号 x，输出其库存数量。

**输入格式**

第一行两个整数 n、q；第二行 n 个整数编号；随后 q 行，每行一个查询编号 x。

**输出格式**

输出 q 行，每行一个库存数量；未出现的编号输出 0。

**数据范围**

1 ≤ n,q ≤ 1,000；所有编号绝对值不超过 10^6。

**样例输入**

```text
5 3
2 7 2 9 7
7
3
2
```

**样例输出**

```text
2
0
2
```

## W03-05 每行总量

一张 n 行 m 列的表格记录整数，计算每一行的总和。

**输入格式**

第一行两个整数 n、m；随后 n 行，每行 m 个整数。

**输出格式**

输出 n 行，第 i 行表示输入表格第 i 行的总和。

**数据范围**

1 ≤ n,m ≤ 100；每个整数绝对值不超过 1,000。

**样例输入**

```text
2 3
1 2 3
-1 0 4
```

**样例输出**

```text
6
3
```

## W03-06 翻转表格坐标

将 n 行 m 列表格转置为 m 行 n 列。原来第 i 行第 j 列的元素，变成第 j 行第 i 列。

**输入格式**

第一行两个整数 n、m；随后 n 行，每行 m 个整数。

**输出格式**

输出转置后的 m 行，每行 n 个整数。

**数据范围**

1 ≤ n,m ≤ 100；每个整数绝对值不超过 1,000。

**样例输入**

```text
2 3
1 2 3
4 5 6
```

**样例输出**

```text
1 4
2 5
3 6
```

## W03-07 网格行走距离

在整数坐标网格中，每步只能向上、下、左、右移动 1 格。对 q 对起终点，求最少步数。没有障碍。建议写一个计算距离的函数。

**输入格式**

第一行一个整数 q；随后 q 行，每行四个整数 x1 y1 x2 y2。

**输出格式**

输出 q 行，每行一个最少步数。

**数据范围**

1 ≤ q ≤ 1,000；坐标绝对值不超过 10^6。

**样例输入**

```text
2
0 0 3 4
-2 5 1 1
```

**样例输出**

```text
7
7
```

## W03-08 第一个独特字母

找出字符串中从左到右第一个只出现一次的字母，输出该字母的位置。位置从 1 开始；不存在则输出 0。

**输入格式**

一行，一个只含小写英文字母的字符串 s。

**输出格式**

输出一个整数位置。

**数据范围**

1 ≤ |s| ≤ 10,000。

**样例输入**

```text
abacbd
```

**样例输出**

```text
4
```
